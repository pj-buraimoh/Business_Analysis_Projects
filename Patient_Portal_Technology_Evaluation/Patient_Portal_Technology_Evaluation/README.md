## Patient Portal Technology Evaluation and Workflow Design

## About This Project

This project looks at how a community health clinic can make some of its administrative services easier for patients to access without having to call or visit the clinic every time.

I focused on three main services:

- Booking appointments.
- Viewing and downloading billing statements.
- Applying for financial assistance and submitting supporting documents.

I looked at different technology options, compared their benefits and limitations, and recommended an approach that could work for the clinic. I also developed a proposed system architecture and workflow diagrams to show how patients and clinic staff would interact with the system.

## Project Status

This is a proposed solution based on my research and analysis. It was not implemented in a live clinic, so the expected benefits have not been measured. Actual vendor capabilities, costs and implementation requirements would need to be confirmed before moving forward.
